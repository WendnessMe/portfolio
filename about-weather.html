Weather and Sound

Weather and Sound, recomendações musicais "climáticas". É bem simples: o usuário insere uma cidade e recebe recomedações de músicas de acordo com o clima atual naquela cidade.

🛠️ Tecnologias Utilizadas

  • Laravel no back end.
  • TailwindCSS + Vite + Javascript no front end.
  • API da OpenWeatherMap para captar os dados meteorológicos.
  • API's do Spotify e do Deezer para pegar as prévias das músicas que combinam com o clima.
  • Servidor FrankenPHP em um container Docker para hospedagem.

☁️ Hospedagem

No momento o projeto está hospedado na Koyeb, que se mostrou ser um PaaS muito prático que o plano gratuito encaixou como uma luva para hospedar um projetinho pequeno. Sem contar que como o projeto está usando Docker, fica bem tranquilo de portar para outra plataforma eventualmente se for necessário. Foi um projetinho até que bem tranquilo que fiz mais para aquecer alguns conhecimentos básicos, como o consumo de API's e criação de containers. Porém ele ainda não está "completo", tenho um checklist de coisas que serão interessantes de implementar para torná-lo mais "redondinho", como, por exemplo: melhorar o sistema de recomendação, melhorar a responsividade e dar um tapa no visual e etc. Por hora estou até que satisfeito com esse MVP, foi um bom exercício para relembrar alguns conceitos e futuramente posso expandir e aprofundar os estudos melhorando o mesmo projeto.
